# Glossary

The terms of the curation, one meaning each. The Drakkar database's terms (publication, run, state, curation pass, description, mapping…) are defined in its `glossary.md`, and used here with that meaning.

| Term | Meaning |
| -- | -- |
| Batch | Publications of a run treated together, at pre-curation or at curation. Never "run". |
| Pool | The publications of a run being downloaded: each stays there until its download is complete, then goes into a batch. A publication whose download cannot be completed stays in the pool and is never curated. |
